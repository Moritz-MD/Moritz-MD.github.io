# Moritz-MD.github.io

Personal academic website of Moritz Diener, served by GitHub Pages at https://moritz-md.github.io.

Plain HTML and CSS, with no build step: `index.html` holds the content and `styles.css` the styling.

- **Update publications:** edit the `#publications` section in `index.html`, keeping it in sync with `papers.bib` in the [cv](https://github.com/Moritz-MD/cv) repo.
- **Pages:** About with research focus (`index.html`), Publications, Projects & Teaching. The header and sidebar are repeated in every file, so change them everywhere.
- **Preview locally:** `python3 -m http.server`, then open http://localhost:8000.
